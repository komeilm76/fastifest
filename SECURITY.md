# Security policy

## Supported versions

Fastifest is pre-release and has not been published. Security fixes should be made against the active development branch; no released version is currently supported.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request. Use GitHub's private vulnerability reporting for this repository if it is enabled. As of 2026-10-30, that setting is disabled and no alternate private contact channel is published here. Before this policy is considered ready for reports, maintainers must enable private vulnerability reporting or add an actual private contact channel to this file. Do not post exploit details publicly while requesting a contact method.

Include the affected Fastifest revision or version, runtime and operating system, a concise impact assessment, and a minimal reproduction where safe. For input-processing reports, use a sanitized fixture that contains no private project assets or secrets.

The project does not promise a response or remediation timeline. Do not test against systems or data you do not own or have explicit permission to assess.
